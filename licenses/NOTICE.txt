BASE — уведомления о сторонних компонентах

1) AndroidX Media3 (Transformer, Effect, ExoPlayer, UI) — Apache License 2.0.
   Подключается как Maven-зависимость; текст лицензии: https://www.apache.org/licenses/LICENSE-2.0

2) Шейдеры переходов (app/src/main/assets/shaders/transitions) — MIT License.
   Полный текст — licenses/transition-shaders-LICENSE.txt. Заголовки авторов внутри каждого .glsl
   сохранены и должны оставаться при любых изменениях/распространении.

3) Шрифты субтитров (app/src/main/res/font): Montserrat, Oswald, Rubik, Russo One, Pacifico —
   SIL Open Font License 1.1. Тексты лицензий: licenses/OFL-*.txt.

4) Распознавание речи — модель Whisper (OpenAI, MIT License), мультиязычная whisper-base в формате
   TFLite из открытого проекта moonshine-ai/openai-whisper (бывш. usefulsensors, MIT License): файл
   модели и словаря/мел-фильтров (assets/asr) используются без изменений; код подготовки звука написан
   для BASE заново на основе описанного там алгоритма. Исполнение модели — LiteRT (Apache License 2.0).
   Модель скачивается автоматически при первом создании субтитров и хранится в памяти приложения.

5) Стилизация субтитров (караоке-подсветка слова, выпрыгивание слова на пружине, жирный контрастный
   текст с обводкой) повторяет подход открытого шаблона для коротких видео; реализация написана для BASE заново,
   исходный код и шрифт шаблона не используются.

6) libPAG (Tencent) — анимированные титры .pag: Apache License 2.0 (сторонний lz4 — BSD-2-Clause).
   Подключается как Maven-зависимость. Шаблоны .pag пользователь импортирует сам.

7) Превью переходов (assets/shaders/transitions/previews) — анимации, сгенерированные для BASE
   из шейдеров переходов (MIT, см. выше) скриптом tools/render_transition_previews.py.

8) Отрисовка текста субтитров (двухслойная: контур STROKE с круглыми стыками + заливка поверх) и
   интерполяция ключевых кадров (пара соседних ключей + линейная интерполяция по нормализованному
   прогрессу) повторяют подход Lottie (Airbnb, Apache License 2.0), файлы model/layer/TextLayer.java
   и animation/keyframe/*; код написан для BASE заново по этой схеме, исходники Lottie не копировались.

9) Жесты трансформации на холсте (перемещение/масштаб/поворот от начального состояния касания,
   относительно центра вписанного кадра) повторяют подход PhotoEditor (burhanrashid52, MIT License),
   файл MultiTouchListener.java; код написан для BASE заново по этой схеме.

10) Распознавание речи: Vosk (alphacep, Apache License 2.0) и компактные модели vosk-model-small-ru-0.22 /
    vosk-model-small-en-us-0.15 (Apache License 2.0); скачиваются приложением при первом запросе субтитров, работают офлайн.

11) JNA (Java Native Access, Apache License 2.0 / LGPL 2.1) — зависимость Vosk.

12) Иконки: Lucide (lucide.dev, ISC License), векторные пути перенесены в ui/theme/Lucide.kt без изменений.
13) Хромакей и удаление фона: сегментация — модель selfie_segmenter (Google MediaPipe, Apache License 2.0) скачивается при первом использовании и запускается через LiteRT.
